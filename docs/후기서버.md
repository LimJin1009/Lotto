# 당첨 인증 후기 서버 (맥미니)

후기는 모든 사람이 함께 보는 게시판이라 서버가 필요하다. 맥미니에서 작은 서버를 돌리고, Tailscale Funnel 로 **이 서버 하나만** 인터넷에 공개한다.

## 구성
| 항목 | 값 |
|---|---|
| 코드 (PC) | `server/reviews-server.mjs`, `server/admin.mjs`, `server/macos/` |
| 코드 (맥미니) | `~/LottoServer/` |
| 데이터 | `~/LottoData/reviews.sqlite` (매일 `backups/` 에 복사, 14개 보관) |
| 기록 | `~/LottoData/logs/server.log` |
| 포트 | `127.0.0.1:3400` (맥미니 안에서만) |
| 자동 실행 | launchd `com.sobunmart.lotto-reviews` (켜지면 시작, 꺼지면 다시 켬) |
| 공개 주소 | `https://yoon-macmini.tail27f282.ts.net:8443` (Funnel, 이 포트만 공개) |
| 앱 설정 | `src/lib/config.ts` 의 `REVIEWS_API` |

- Node 24 기본 기능만 쓴다 (`node:http`, `node:sqlite`). 설치할 라이브러리 없음.
- 당첨번호는 서버가 공개 데이터(smok95/lotto)에서 받아 DB에 저장해 둔다. 비밀 키 없음.
- OrderFlow(3200)·오토진(3300)·마켓봄 실행기는 건드리지 않는다. 기존 Tailscale serve(443 → 3200, tailnet 전용)도 그대로.

## 규칙 (서버가 지킴)
- 복권 QR 글자를 서버가 다시 풀고, 서버의 당첨번호와 맞춰 등수를 정한다. 5등(3개) 이상만 저장, 꽝 거절.
- 같은 복권의 같은 게임은 한 번만 (QR 글자+게임의 SHA-256).
- 닉네임 1~12자, 후기 5~300자, 요청 8KB까지.
- 도배 막기: 한 곳에서 10분에 5번, 서버 전체 1시간에 300번.
- 이 사이트(limjin1009.github.io)에서 온 요청만 브라우저가 읽을 수 있게 허락(CORS).

## 처음 공개할 때 (누나가 한 번)
Funnel 은 Tailscale 계정 주인이 허용해야 켜진다.
1. https://login.tailscale.com/f/funnel?node=ntkWkfxdFc11CNTRL 을 열고 누나 계정으로 로그인 → 허용.
2. Claude 가 맥미니에서 `tailscale funnel --bg --https=8443 http://127.0.0.1:3400` 실행.

## 코드 바꾼 뒤 올리기
```bash
scp server/reviews-server.mjs server/admin.mjs macmini:LottoServer/
ssh macmini 'zsh ~/LottoServer/macos/install.sh restart'
```

## 관리 (맥미니에서)
```bash
cd ~/LottoServer && fnm exec --using=24 node admin.mjs list          # 최근 30개
cd ~/LottoServer && fnm exec --using=24 node admin.mjs hide <id앞8자>  # 숨기기
cd ~/LottoServer && fnm exec --using=24 node admin.mjs delete <id앞8자>
zsh ~/LottoServer/macos/install.sh off                               # 서버 끄기
/Applications/Tailscale.app/Contents/MacOS/Tailscale funnel --https=8443 off   # 공개 끄기
```

## 알아둘 점
- 맥미니가 꺼지거나 인터넷이 끊기면 후기만 멈춘다 (번호 뽑기·QR 확인은 그대로).
- 오토진이 M8 미니PC로 옮겨 가도 후기 때문에 맥미니는 켜 둔다. 옮기려면 `~/LottoData` 를 통째로 복사.
