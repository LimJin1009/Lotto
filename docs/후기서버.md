# 당첨 인증 후기 서버 (Cloudflare)

후기는 모든 사람이 함께 보는 게시판이라 서버가 필요하다. Cloudflare Workers(무료)에 작은 서버를 올리고, 데이터는 Cloudflare D1(SQLite)에 둔다. 가게 컴퓨터(맥미니)와 완전히 떨어져 있다.

## 구성
| 항목 | 값 |
|---|---|
| 코드 | `worker/src/reviews.mjs` (규칙·처리), `worker/src/index.mjs` (진입), `worker/schema.sql` (표) |
| 설정 | `worker/wrangler.toml` (이름 `lotto-reviews`, D1 연결) |
| 데이터 | D1 `lotto-reviews` (표: `reviews`, `draws`, `hits`) |
| 공개 주소 | `https://lotto-reviews.lottojjin.workers.dev` (계정 dlawls3355, workers.dev 이름 `lottojjin`) |
| 앱 설정 | `src/lib/config.ts` 의 `REVIEWS_API` |
| 무료 한도 | 하루 요청 10만 번, 저장 5GB (넘으면 그날만 멈춤) |

- 라이브러리 없이 Workers 기본 기능만 쓴다. 당첨번호는 서버가 공개 데이터(smok95/lotto)에서 받아 DB에 저장해 둔다. 비밀 키 없음.
- 시험: `npx vitest run worker` (내 PC의 SQLite 로 D1 을 흉내 내서 돌림).

## 규칙 (서버가 지킴)
- 복권 QR 글자를 서버가 다시 풀고, 서버의 당첨번호와 맞춰 등수를 정한다. 5등(3개) 이상만 저장, 꽝 거절.
- 같은 복권의 같은 게임은 한 번만 (QR 글자+게임의 SHA-256).
- 닉네임 1~12자, 후기 5~300자, 요청 8KB까지.
- 도배 막기: 한 곳에서 10분에 5번, 서버 전체 1시간에 300번. IP 는 그대로 저장하지 않고 해시만, 1시간 지나면 지운다.
- 이 사이트(limjin1009.github.io)에서 온 요청만 브라우저가 읽을 수 있게 허락(CORS).

## 처음 올릴 때 (한 번)
1. **누나:** https://dash.cloudflare.com/sign-up 에서 가입 (이메일 인증까지).
2. **누나:** PC 에서 `cd D:\Project\Lotto\worker` 후 `npx wrangler login` → 브라우저가 열리면 Cloudflare 로그인 후 **Allow**.
3. **Claude:**
   ```bash
   cd worker
   npx wrangler d1 create lotto-reviews          # 나온 database_id 를 wrangler.toml 에 넣기
   npx wrangler d1 execute lotto-reviews --remote --file schema.sql
   npx wrangler deploy                           # 나온 workers.dev 주소 확인
   ```
4. **Claude:** 나온 주소로 `/health` 확인 → `src/lib/config.ts` 의 `REVIEWS_API` 에 넣고 커밋 (GitHub 에는 "올려줘" 때).

## 코드 바꾼 뒤 올리기
```bash
npx vitest run worker
cd worker && npx wrangler deploy
```

## 관리 (PC 에서, worker 폴더)
```bash
# 최근 30개
npx wrangler d1 execute lotto-reviews --remote --command "SELECT substr(id,1,8) id, created_at, round, rank, nickname, content, hidden FROM reviews ORDER BY created_at DESC LIMIT 30"
# 숨기기 / 다시 보이기 (id 앞 8자)
npx wrangler d1 execute lotto-reviews --remote --command "UPDATE reviews SET hidden = 1 WHERE id LIKE 'abcd1234%'"
npx wrangler d1 execute lotto-reviews --remote --command "UPDATE reviews SET hidden = 0 WHERE id LIKE 'abcd1234%'"
# 파일로 백업
npx wrangler d1 export lotto-reviews --remote --output ../backup-reviews.sql
```
- D1 은 지난 시점으로 되돌리기(Time Travel)를 해 준다: `npx wrangler d1 time-travel restore lotto-reviews --timestamp <시각>`.
