# 로또 찐번호 — 로또 번호 생성기

꿈 해몽, 생일·전화번호·차량번호, 역대 당첨 통계, 추첨기 애니메이션으로 로또 번호를 만드는 웹앱입니다.
만든 번호마다 **그 숫자가 왜 나왔는지** 알려주고, 내 번호함에 저장하면 추첨 뒤 자동으로 당첨을 맞춰 봅니다.

> 재미로 보는 번호입니다. 어떤 방법으로 만들어도 모든 조합의 당첨 확률은 같습니다 (1등 8,145,060분의 1).

- 사이트: https://limjin1009.github.io/Lotto/
- 기획: [docs/기획서.md](docs/기획서.md)

main에 올리면 GitHub Actions가 자동으로 배포합니다. 매주 일요일 10:00(한국 시간)에도 최신 당첨번호를 받아 다시 배포합니다.

## 1차 기능

홈 화면에서 방식을 고르면, 가운데 **공기식 추첨기**에서 공이 날아다니다가 그 방식으로 정한 번호가 하나씩 나옵니다.

- 🌙 **꿈 해몽** — 38가지 꿈 × 세부 상황
- 🎂 **나만의 숫자** — 생일·전화번호·차량번호·기념일·아무 숫자 (최대 3개 섞기)
- ✍️ **이름·소원** — 이름이나 소원 문장을 글자마다 숫자로 (같은 문장 → 같은 번호)
- 📈 **통계** — 많이 나온 번호 / 오래 안 나온 번호 / 균형 조합
- 🎱 **자동 추첨** — 아무것도 넣지 않고 공 6개를 자동으로
- 🔍 **당첨 확인** — 복권 QR을 찍거나 사진에서 찾거나 번호를 직접 넣으면 등수·당첨금 확인
- 🏆 **당첨 인증 후기** — 복권 QR로 확인한 5등 이상만, 서버가 등수 판정 (설정: [docs/supabase-설정.md](docs/supabase-설정.md))
- 📲 **휴대폰 설치** — 상단 "앱 설치"로 홈 화면에 추가 (앱 마켓 없이)
- 🗂️ **내 번호함** — 기기에 저장, 추첨 뒤 등수 자동 확인
- 📊 **통계** — 번호별 당첨 횟수, 오래 안 나온 번호, 최근 10회

## 실행

```bash
npm install
npm run dev          # 개발 서버
npm test             # 테스트
npm run build        # dist/ 에 배포용 파일 생성 (정적 호스팅 어디든 가능)
npm run update-draws # 앱 안의 당첨번호 데이터 새로 받기
npm run icons        # assets/icon.svg 로 앱 아이콘 PNG 다시 만들기
```

## 당첨번호 데이터

[smok95/lotto](https://github.com/smok95/lotto)의 공개 데이터(동행복권 결과)를 씁니다.
앱 안에 `src/data/draws.json`이 들어 있고, 앱을 열 때 새 회차가 있으면 받아서 기기에 저장합니다.
