# 오늘의 번호 — 로또 번호 생성기

꿈 해몽, 생일·전화번호·차량번호, 역대 당첨 통계, 추첨기 애니메이션으로 로또 번호를 만드는 웹앱입니다.
만든 번호마다 **그 숫자가 왜 나왔는지** 알려주고, 내 번호함에 저장하면 추첨 뒤 자동으로 당첨을 맞춰 봅니다.

> 재미로 보는 번호입니다. 어떤 방법으로 만들어도 모든 조합의 당첨 확률은 같습니다 (1등 8,145,060분의 1).

기획: [docs/기획서.md](docs/기획서.md)

## 1차 기능

- 🌙 **꿈 해몽 번호** — 38가지 꿈 × 세부 상황
- 🎂 **나만의 숫자** — 생일·전화번호·차량번호·기념일·아무 숫자 (최대 3개 섞기)
- 📈 **통계 분석** — 많이 나온 번호 / 오래 안 나온 번호 / 균형 조합
- 🎱 **추첨기** — 45개 공이 섞이고 7개가 차례로 나오는 애니메이션
- 🗂️ **내 번호함** — 기기에 저장, 추첨 뒤 등수 자동 확인
- 📊 **통계** — 번호별 당첨 횟수, 오래 안 나온 번호, 최근 10회

## 실행

```bash
npm install
npm run dev          # 개발 서버
npm test             # 테스트
npm run build        # dist/ 에 배포용 파일 생성 (정적 호스팅 어디든 가능)
npm run update-draws # 앱 안의 당첨번호 데이터 새로 받기
```

## 당첨번호 데이터

[smok95/lotto](https://github.com/smok95/lotto)의 공개 데이터(동행복권 결과)를 씁니다.
앱 안에 `src/data/draws.json`이 들어 있고, 앱을 열 때 새 회차가 있으면 받아서 기기에 저장합니다.
